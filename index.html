台子同步IrisEros 是独立开发的第三方调音台同步工具，支持单控台、双控台全镜像和双控台显示独立模式，并提供可选的 All Live 接入。

Mac 版免费下载，全部功能可用，无需激活码。需要兼容的 WING 系列硬件及局域网连接。

开始连接

  1. 让 Mac 与调音台位于可互通的局域网，确认两台调音台的 IP 地址。
  2. 首次启动阅读使用说明，选择用于保存导出文件的文件夹。
  3. 输入 A、B 调音台 IP，选择主台及需要的同步模式。启动同步前确认设备型号、固件与当前配置。
  4. 需要 All Live 时，开启接入，将 All Live 连接到主界面显示的本机 IP。回读来自当前主台，另一台通过已有同步机制跟随。

本软件不是调音台厂商官方产品，也不是演出安全保障系统。支持范围取决于设备型号、固件与实时参数定义；请先完成可控环境测试，并保留人工接管和停止同步手段。

常见问题

找不到调音台：核对 IP 与网段，检查 macOS 本地网络权限、网络路由及应用防火墙权限。不要为排查问题关闭系统整体安全保护。

All Live 读回不同：先确认当前主台及 All Live 连接的本机 IP，查看运行日志。不要同时开启多个代理或同步程序控制同一组设备。

重启后无法保存：到“总设置”重新选择保存文件夹，使用系统文件夹选择器授予访问权限。

异常或同步中断：停止同步、保留现场信息，导出错误报告。不要在正式演出中反复尝试未验证的恢复操作。
